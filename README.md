<h1>Python : NumPy & Pandas Cookbook</h1>

<p>
  Beginner-friendly <strong>Jupyter Notebook cookbooks</strong> that demonstrate essential
  <strong>NumPy</strong> and <strong>Pandas</strong> techniques for data science and machine learning.
</p>

<h2>Contents</h2>
<ul>
  <li>
    <strong><code>Numpy_Cookbook.ipynb</code></strong>
    <ul>
      <li>Array creation, indexing, slicing, reshaping</li>
      <li>Mathematical and statistical operations</li>
      <li>Broadcasting and vectorization</li>
      <li>Useful NumPy functions with examples</li>
    </ul>
  </li>
  <li>
    <strong><code>Pandas_Cookbook.ipynb</code></strong>
    <ul>
      <li>Series & DataFrame creation</li>
      <li>Indexing, filtering, and selection</li>
      <li>Handling missing values</li>
      <li>Grouping, merging, and joining</li>
      <li>Descriptive statistics and basic visualization</li>
    </ul>
  </li>
</ul>

<h2>Why This Repository?</h2>
<p>
  Learn <em>step-by-step</em> with practical examples. These notebooks serve as a quick reference for essential NumPy and Pandas methods and are ideal when starting with data analysis or machine learning.
</p>

<h2>Pre-requisite Skills</h2>
<ul>
  <li>Basic knowledge of Python coding</li>
  <li>Operational knowledge about Jupyter Notebook</li>
</ul>

<h2>How to Use</h2>
<p>Clone the repository and open the notebooks in Jupyter or JupyterLab or Google Colab. Run cells interactively to explore examples and outputs.</p>
<pre>
<code># Clone the repository
git clone https://github.com/Iftikhar-Shams-Niloy/Python-Numpy-Pandas.git
cd Python-Numpy-Pandas

# Launch Jupyter Notebook
jupyter notebook
</code>
</pre>

<h2>Requirements</h2>
<p>You will need Python 3.x, Jupyter Notebook, NumPy and Pandas. Install dependencies if necessary:</p>
<pre>
<code>pip install numpy pandas jupyter</code>
</pre>
